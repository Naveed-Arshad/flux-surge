# ⚡ FLUX SURGE - Web-Only Tap-to-Earn Game

**A simple, addictive tap-to-earn game built for the web!**

## 🚀 What's Inside?

```
flux-surge-backend.js      → Backend (Node.js + Express)
flux-surge-frontend.html   → Game UI (HTML/CSS/JS)
flux-surge-schema.sql      → Database (PostgreSQL)
package.json               → Dependencies
.env.example               → Configuration
SETUP_GUIDE_WEB.md         → Complete setup steps
README.md                  → This file
```

## ✨ Features

✅ **Simple Login** — Just enter username, start playing  
✅ **Tap to Earn** — Click hamster, get coins  
✅ **Energy System** — Limited energy, regenerates over time  
✅ **Upgrades** — 6 different upgrades to boost earnings  
✅ **Passive Income** — Earn coins while away (bots)  
✅ **Daily Rewards** — Login bonus with streak tracking  
✅ **Referral System** — Invite friends, get bonus coins  
✅ **Real-time Sync** — All data saved to database  

## 🎮 Quick Demo Flow

1. User opens game URL
2. Enters username (3+ characters)
3. Clicks "Play" → Account created
4. Taps hamster icon → Earns coins
5. Buys upgrades to increase earnings
6. Claims daily bonus (with streak)
7. Earns passive income from bots

## 🛠️ Tech Stack

- **Backend:** Node.js + Express.js
- **Database:** PostgreSQL (Supabase)
- **Frontend:** HTML/CSS/JavaScript
- **Hosting:** Railway (backend) + Vercel (frontend)
- **Authentication:** Simple username-based
